# openEHR archetype and operational template

This directory holds the openEHR modelling artefacts for storing derived
dose-volume parameters in a clinical data repository — the Level 2 to Level 3
pathway described in the manuscript.

| File | What it is |
|------|------------|
| `openEHR-EHR-CLUSTER.radiotherapy_dvh.v0.adl` | The DVH parameter archetype (ADL 1.4) |
| `dvh_report.opt` | Operational template, ready to upload to an openEHR CDR such as EHRbase |

## The archetype

`CLUSTER.radiotherapy_dvh.v0` records arbitrary dose-volume parameters per
structure. Metric names are deliberately **not** enumerated, so any current or
future parameter (V20, V55, D2, D95, D0.03cc, Dmean, gEUD, NTCP, ...) can be
stored without a schema change — the same design principle as the DVH cache
itself: keep the general form, derive the specific parameter on demand.

It is designed to sit in the "Specific details" SLOT (`at0021`) of
`CLUSTER.radiotherapy.v0`. Treatment-level data (prescription dose, fractions,
technique) belong in that parent archetype, and procedure-level timing belongs
in the grandparent `ACTION.procedure.v1` — this archetype deliberately does not
duplicate them.

Full DVH curves are **not** stored here. They stay in the DICOM RT DVH cache
(PS3.3 C.8.8.4); only derived per-structure parameters are written onward.
